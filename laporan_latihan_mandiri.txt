===============================================================
4. CHALLENGE - BINGKAI DAN DIAGONAL
===============================================================

Berkas: latihan_mandiri_04.c

Hasil ukuran 5:
# # # # #
# X . . #
# . X . #
# . . X #
# # # # #

Hasil ukuran 3:
# # #
# X #
# # #

Aturan prioritas sudah diterapkan:
1. Posisi bingkai selalu menghasilkan '#'.
2. Posisi diagonal utama menghasilkan 'X' jika bukan bingkai.
3. Posisi lainnya menghasilkan '.'.

===============================================================
5. DIAGONAL UTAMA VS SEKUNDER
===============================================================

Berkas: latihan_bonus_09.c

Contoh 1
Input:
3
2 4 6
1 3 5
9 8 7

Output:
========================================
       DIAGONAL UTAMA VS SEKUNDER
========================================
Diagonal utama    : 12
Diagonal sekunder : 18
----------------------------------------
Selisih           : -6
========================================

Contoh 2
Input:
2
10 0
0 10

Output:
========================================
       DIAGONAL UTAMA VS SEKUNDER
========================================
Diagonal utama    : 20
Diagonal sekunder : 0
----------------------------------------
Selisih           : 20
========================================

Contoh 3
Input:
1
5

Output:
========================================
       DIAGONAL UTAMA VS SEKUNDER
========================================
Diagonal utama    : 5
Diagonal sekunder : 5
----------------------------------------
Selisih           : 0
========================================

Catatan:
- Program bonus tidak menampilkan prompt input agar output tetap sesuai
  format yang diminta.
- Garis pembatas menggunakan 40 karakter '=' dan 40 karakter '-'.
- Semua program dikompilasi dengan:
  gcc -std=c17 -Wall -Wextra
- Tidak ada error atau warning.
